Local LLM Agent MVP

This project uses Ollama to run language models on your machine.
RAG (Retrieval-Augmented Generation) stores document chunks in ChromaDB
and retrieves relevant passages before answering.

FastAPI exposes health, ingest, chat, personas, and models endpoints.
LangGraph orchestrates retrieve, generate, and optional tool steps.
FastMCP provides sample tools such as getting the current time.

To start Ollama, install from https://ollama.com and run:
  .\scripts\setup-models.ps1

The default chat model is local-agent (Gemma 4 E4B, vision + tools).
Embeddings use embeddinggemma. Optimized for RTX 4060 8GB VRAM.
